# Project Documentation

This folder contains the working documentation for the AI-powered document intelligence platform.

- `overview.md` explains the product goal, local-first AI direction, and major features.
- `frontend.md` documents the React frontend structure and user workflows.
- `backend.md` documents backend services, providers, storage, and data flow.
- `api-reference.md` lists every exposed backend API and its purpose.
- `local-ai-setup.md` explains how to run the project without an OpenAI API key.
